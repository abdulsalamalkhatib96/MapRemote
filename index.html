HTTPS certificate

Install the local CA once to enable HTTPS mapping on selected hosts. Unrelated HTTPS connections retain their original certificates. This grants the CA SSL trust for your macOS user account; install only on a development Mac you control. Approve the macOS trust prompt. Older system-wide installations can be removed in Keychain Access.
